

# Smart Irrigation System — STM32F103C8T6

An automatic irrigation controller built on the STM32 Blue Pill (STM32F103C8T6),
developed for NSU CSE331. The system monitors soil moisture, rainfall, water tank
level, temperature, and humidity, and drives a water pump via relay based on
configurable thresholds with hysteresis, safety cutoffs, and manual override.

## Features

- Soil moisture sensing (capacitive, analog) with dry/wet calibration
- Water-level sensing (analog) with low-water cutoff
- Rain detection (digital, LM393-based module)
- Temperature & humidity via DHT11 (bit-banged single-wire protocol)
- SSD1306 OLED (I2C) with cycling info/status/warning screens
- Automatic irrigation logic with hysteresis (no relay chatter in the dead zone)
- Priority safety logic: low water and rain always override soil-based irrigation
- AUTO / MANUAL mode switch
- Pump safety timeout (max continuous runtime cutoff)
- Sensor fault detection (DHT/soil out-of-range)
- Buzzer + status LEDs for warnings

## Calibration Constants

```c
// Soil moisture (soil_moisture.h)
#define SOIL_ADC_DRY   3300
#define SOIL_ADC_WET   3000

// Water level (water_level.h)
#define WATER_ADC_EMPTY       300
#define WATER_ADC_FULL        1000
#define WATER_LEVEL_LOW_RAW   500

// Irrigation thresholds (irrigation.h)
#define SOIL_DRY_THRESHOLD   35   // % — pump ON below this
#define SOIL_WET_THRESHOLD   60   // % — pump OFF at/above this
#define PUMP_MAX_RUNTIME_MS  30000 // safety cutoff
```

> These values are specific to the sensors/units used during development and should
> be re-calibrated for any different hardware batch.

## Irrigation Logic

```
IF water level is LOW        -> Pump OFF, Warning ON
ELSE IF rain is detected     -> Pump OFF
ELSE IF soil moisture < 35%  -> Pump ON
ELSE IF soil moisture >= 60% -> Pump OFF
ELSE                          -> hold previous pump state (hysteresis)
```

AUTO/MANUAL switch (PB1) forces the pump on in MANUAL mode *only* when water
level and rain conditions are safe — safety checks are never bypassed by
manual mode.

Pump has a maximum continuous runtime cutoff (`PUMP_MAX_RUNTIME_MS`); on
timeout the pump is stopped and a warning is raised.

1. Open the project in STM32CubeIDE.
2. Build (Project → Build Project).
3. Connect ST-Link V2, flash via Run/Debug or STM32CubeProgrammer.
